# Ubuntu Urban Wear

## Project Overview
Ubuntu Urban Wear is a basic responsive website prototype for a proposed South African streetwear organisation.

## Mission
To provide affordable, stylish and accessible fashion while delivering a convenient shopping experience.

## Vision
To become a recognised South African online fashion brand known for quality, affordability and customer service.

## Website Features
- Responsive navigation
- Home, About, Products and Contact sections
- Demo Add to Cart functionality
- Contact form
- Facebook, X, YouTube and Instagram links
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## How to Run
Open `index.html` in a web browser.

## Notes
The cart and contact form are front-end demonstrations only. Social links currently point to the platform homepages.
