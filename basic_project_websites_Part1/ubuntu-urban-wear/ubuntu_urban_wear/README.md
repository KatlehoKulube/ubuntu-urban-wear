# Ubuntu Urban Wear

## Project Overview
Ubuntu Urban Wear is a basic responsive website prototype for a proposed South African streetwear and contemporary fashion organisation.

The website is aimed at students, young professionals and digitally active consumers aged approximately 18–35.

## Mission
To provide affordable, stylish and accessible fashion while delivering a convenient shopping experience.

## Vision
To become a recognised South African online fashion brand known for quality, affordability and customer service.

## Website Purpose
The website is designed to:
- Establish an online presence
- Promote the Ubuntu Urban Wear brand
- Display products
- Generate customer interest and enquiries
- Demonstrate basic e-commerce functionality
- Connect users with social media platforms

## Features
- Responsive navigation
- Ubuntu Urban Wear logo
- Home / hero section
- About Us section
- Mission and Vision
- Target Audience information
- Featured Products
- Demo Add to Cart buttons
- Contact form
- Facebook, X, YouTube and Instagram links
- Mobile responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html`
- `style.css`
- `script.js`
- `images/logo.png`
- `README.md`

## How to Run
Open `index.html` in a modern web browser.

## Current Limitations
The shopping cart and contact form are demonstration features only. They are not connected to a database, payment gateway, backend server or email delivery service.

The social media links currently open the main Facebook, X, YouTube and Instagram websites because official Ubuntu Urban Wear profiles have not yet been added.
